# CFP Expansion & Non-Conference Scheduling

**DTSC 2301 — Portfolio Project 1**
Author: [Your Name]

## Research Question

Has the expansion of the College Football Playoff from 4 to 12 teams
changed how Power Conference teams schedule non-conference opponents?
Specifically, did the average non-conference opponent win percentage
drop in the 2024–2025 season compared to the four-team era (2014–2023)?

## Project Structure

- `data/` — raw and cleaned datasets of team schedules and opponent win percentages
- `notebooks/` — Jupyter notebook(s) containing the data collection, cleaning, and analysis
- `docs/` — the published write-up / website version of the findings

## Data Source

Schedule and results data pulled from [collegefootballdata.com](https://collegefootballdata.com).

## How to Run This Project

1. Clone this repository
2. Create a virtual environment and activate it
3. Install dependencies: `pip install -r requirements.txt`
4. Open `notebooks/analysis.ipynb` and run the cells in order
